# kangheng-minutes（康恒会议纪要规范 · 公开框架版）

把会议录音转写稿整理成**正式决议式会议纪要**的 skill 规范：决议纯度、条目写法、数据规则、语言规范、分节归属、输出结构、句式规范、工作流程。

## 核心原则

纪要 = 决议清单，不是讨论记录。每条自检：这条不写，会后执行会不会出偏差？不会就删。

## 仓库结构

- `SKILL.md` —— 全部规范，可直接作为智能体指令或 Hermes/Claude Code 类工具的 skill 使用。

## 脱敏说明

本仓库为公开框架版。以下内容**不随仓库公开**，使用时需在智能体平台内以附件/知识库形式单独配置：

- 会议纪要统一词库（标准词/禁用变体）
- 人名转写对照表（语音转写 → 标准人名）
- 历史定稿正例、公司官方 Word 模板

SKILL.md 中引用上述附件处，请确认附件已就位后再成稿。

## 用法

1. **智能体平台（Multica / 元器 / Coze 等）**：导入本仓库或粘贴 `SKILL.md` 全文，附件单独上传。
2. **Hermes skill**：将 `SKILL.md` 放入 skills 目录。
3. **直接当 prompt**：粘贴全文 + 上传附件即可。
